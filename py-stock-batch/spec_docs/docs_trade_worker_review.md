# trade_worker 코드 리뷰 (2026-07-30)

주문→체결 확인, 계좌 확인, 주문 수량 계산 중심 전체 점검. **수정 완료 / 남은 리스크**로 구분.

---

## 수정 완료 (이번 리뷰)

### 1. 매도 동시성 중복주문 (Critical) — 수정
실시간 시세 소켓은 콜백을 **멀티스레드**로 호출한다. 기존엔 `_do_sell` 진입 가드가
`_sold` 뿐이라, `wait_fill`(체결 확인, 수 초 소요) 동안 여러 틱이 동시에 통과해
**같은 종목 매도가 여러 번** 나갈 수 있었다.
→ `threading.Lock` + `_inflight` set 으로 종목당 1건만 진행하도록 수정.
(검증: 동시 20틱 → 실제 주문 1건)

### 2. `_sold` 미초기화 → 재매수 종목 매도 영구 차단 — 수정
`_sold` 가 프로세스 수명 내내 유지돼, 매도한 종목을 나중에 재매수하면 다시는 매도가
안 됐다. → `reload_positions`(개장 1일 1회)에서 `_sold` 초기화 + positions 를 active 로 재구성.

### 3. 시세 재구독 중복 — 수정
개장마다 `reload_positions` 가 같은 종목을 또 구독(콜백 중복·티켓 누수).
→ `_subscribed` set 으로 신규 종목만 구독.

### 4. 매수 수량 계산 개선 — 수정
기존 `예수금 // 현재가` 는 부정확(예수금 ≠ 주문가능현금; 증거금·미수·D+2 미반영).
→ **매수가능조회**(`stock.orderable_amount`)의 `최대매수수량·주문가능현금` 우선 사용,
조회 실패 시에만 예산기준 fallback. `BUY_BUDGET_RATIO` 버퍼는 유지.

### 5. 매수 미체결(PENDING) 방치 → 유령 체결 — 부분 수정
`wait_fill` 타임아웃(PENDING, 0체결)인데 주문은 살아있어 나중에 체결되면 DB에 없는
포지션이 생긴다. → PENDING 시 `broker.cancel()` 로 취소 시도(best-effort) 후 중단.

## 남은 리스크 (실계좌 검증 단계에서 확정)

### A. 주문번호 매칭 (체결 확인의 근간)
`wait_fill` 은 `order.order_number` 와 체결통보 `execution.order_number` 를 `_ono()`(=`.number`)
문자열로 매칭한다. KIS 는 주문번호가 **지점번호(branch)+번호** 조합이라, 동일 번호가
지점 간 겹칠 여지가 있다. 실계좌에서 branch 까지 포함해 매칭하는지 실측 필요.

### B. 부분체결(PARTIAL) 잔여 처리
현재 PARTIAL 도 체결분만 기록하고 종료(매도는 sold 처리). **잔여수량 재주문/정정** 미구현.
시장가라 대개 전량 체결되지만, 유동성 낮은 종목·대량주문 시 잔여가 남을 수 있다.

### C. 취소(cancel)·미체결 조회의 모의투자 미지원
`pending_orders()`·정정취소는 **모의투자 미지원**. 그래서 모의에선 체결확인이 전적으로
**실시간 체결통보**에 의존하고, PENDING 취소도 실전에서만 동작. 모의 검증 시 이 차이 유의.

### D. 예수금(account_cash) vs 주문가능현금
잔고 동기화는 `deposit('KRW').amount`(예수금)를 쓴다. 매수 사이징은 주문가능현금으로
바꿨지만, `user_wallet` 동기화는 예수금 기준이라 **미수/증거금 계좌**에선 둘이 다를 수 있다.
단순 현금계좌면 무방.

### E. 동일종목 라인 없음 구간 (설계상)
갓 매수한 종목은 daily 배치가 stop/target/trail 을 채우기 전까지 **실시간 손절 라인이 없다**.
그 사이 급락 시 개장 전까지 보호가 없음. spec 상 라인은 daily 산출이지만, 필요하면
매수 직후 임시 손절가(예: entry×(1−stop_loss_pct))를 즉시 세팅하는 보완 고려.

### F. 기타(경미)
- `trade_log` 의 `fee`/`pnl` 미계산(0 고정).
- `broker._fills` dict 는 종료 전까지 누적(장기 구동 시 소량 메모리 증가).
- 매수 수량은 시초가 근처 현재가로 산정 → 실제 시장가 체결과 미세 괴리(시장가라 수량 고정은 유지).
