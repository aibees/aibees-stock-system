## 1. 방향

- 지금의 양봉상회는 CEO 1인용 앱이다. 대중 공개용으로 바꾼다. **[확정]**
- 핵심: 주식을 몰라도 쓸 수 있는 접근성. 어려운 용어는 쉬운 말로 바꾸고, 꼭 필요한 용어는 쓰면서 익히게 한다. **[확정]**
- 대표 메시지: **성향 맞춤 종목.** 문구는 사용자가 주어인 형태로 쓴다. **[확정]**
  - 예: "내 성향으로 시작해서, 내 조건으로 골라 보는 종목 앱"
  - 항상 "투자 판단과 책임은 본인에게 있다"는 고지를 함께 둔다.
- 편의 기능(가이드, 쉬운 용어)과 성적표 공개는 부가 기능이다. 대표 메시지로 쓰지 않는다. **[확정]**
- 톤: 진지하게. 캐릭터, 경험치·별 같은 게임 연출은 쓰지 않는다. **[확정]**
- 범위 밖: 자동매매, 실시간 소켓. 대중 공개 계획이 없으며 이번 개편에서 다루지 않는다. **[확정]**

### 타겟
| 구분 | 대상 | 제공하는 것 |
|---|---|---|
| 1차 | 계좌는 있지만 종목을 고를 기준이 없는 사람 | 성향 테스트로 정한 시작 설정, 쉬운 말 설명 |
| 2차 | 자기 기준을 만들고 싶은 경험자 | 세부 설정 조정, 전문가용 고급 조건, 백테스트 |

## 2. 전체 사용 흐름

1. 온보딩: 성향 질문 5개 (가입 불필요)
2. 결과 화면: 유형 제안 → 사용자가 직접 선택해 확정
3. 홈: 시황 → 시장이 주목하는 종목 → 지난달 성과
4. 설정 조정: 익숙해지면 조건을 직접 바꿈 (단계적으로 개방)
5. 가입: 설정 저장·알림이 필요할 때
6. 백테스트: 내 조건을 과거 데이터로 확인 (1년 무료, 그 이상 구독)

## 3. 온보딩

### 3.1 진입 지점 **[확정]**
- 앱을 처음 설치해 실행했을 때
- 홈 상단의 안내 버튼("처음이세요?")을 눌렀을 때 — 언제든 다시 볼 수 있다

### 3.2 형태
- A/B 테스트로 결정한다. **[확정]**
  - A안: 소개 슬라이드 3장 후 질문
  - B안: 소개 없이 질문으로 바로 시작
- 사용자가 적으면 A/B 결과가 의미 없으므로, 공개 전에는 지인 5명 관찰로 먼저 거른다. **[권고]**
- 화면 규칙: 한 화면에 질문 하나, 상단 진행 바, 건너뛰기 버튼 필수. **[권고]**
- 참고 자료(INVESTING101)에서 가져올 것 **[권고]**
  - 선택지를 사용자 입말로 쓴다
  - 알림 허용을 묻기 전에 이유를 먼저 말하고 "나중에"를 둔다 (예: "살 만한 가격에 오면 알려드립니다")
  - 설정 확정 직후 첫 종목 카드에서 "이유 → 살 만한 가격 → 정리할 가격"을 순서대로 짚어준다 (30초 이내)
- 가져오지 않을 것 **[확정/권고]**
  - 캐릭터 진행 **[확정]**
  - "N개월 내 달성" 식의 약속 화면 — 수익 약속으로 읽힌다
  - 온보딩 중 위젯 추가 안내 — 앱 밖으로 나가야 한다
  - 긴 학습 과정

### 3.3 성향 질문 5개 **[확정]**

| # | 질문 | 선택지 A | 선택지 B | 정하는 것 |
|---|---|---|---|---|
| 1 | 주식을 사 본 경험이 있으신가요? | 아직 없습니다 / 몇 번 사 봤습니다 | 꾸준히 하고 있습니다 | 간편 모드 / 전문가 모드 제안 |
| 2 | 산 종목을 얼마나 지켜볼 생각이신가요? | 몇 주는 기다릴 수 있습니다 | 며칠 안에 결과를 보고 싶습니다 | 보유 기간 |
| 3 | 산 종목이 일주일 만에 10% 내렸습니다. 어떻게 하시겠습니까? | 더 내리기 전에 정리합니다 | 정해 둔 가격까지는 지켜봅니다 | 정리할 가격의 폭 |
| 4 | 어느 쪽이 더 마음 편하신가요? | 조금씩 꾸준히 움직이는 종목 | 크게 오르내려도 기회가 큰 종목 | 가격 변동 크기 |
| 5 | 어떤 회사에 더 눈이 가시나요? | 이름을 들어 본 큰 회사 | 덜 알려졌지만 요즘 주목받는 회사 | 회사 규모 |

- 1번은 선택지 3개(점수 없음, 모드 제안용). 2~5번은 2지선다.
- 주식 용어를 쓰지 않는다. 투자금·보유 종목·수입 같은 개인 사정은 묻지 않는다.

### 3.4 결과 계산
2~5번에서 B를 고른 개수.

| B 개수 | 제안 유형 | 시작 설정 방향 |
|---|---|---|
| 0~1 | 안정형 | 큰 회사 위주, 변동 작은 종목, 정리할 가격을 가깝게 |
| 2 | 균형형 | 중간값 |
| 3~4 | 공격형 | 중소형 포함, 변동 큰 종목, 정리할 가격을 멀게 |

- 유형은 3개로 시작한다. 추가·명칭 변경 가능성을 열어둔다. **[확정]** → 유형을 코드에 하드코딩하지 말고 데이터로 관리할 것.
- 유형별 실제 설정 수치는 개발팀이 기존 조건에 맞춰 정한다. **[미결]**

### 3.5 결과 화면 **[확정]**
- 유형 하나를 "제안"하고, 사용자가 세 유형 중 직접 골라 "이 설정으로 시작"을 눌러 확정한다. 자동 적용하지 않는다.
- "시작 설정 제안이며 언제든 바꿀 수 있습니다" 문구를 넣는다.
- 가입 없이 끝까지 진행된다.

## 4. 홈 화면

### 4.1 구성 순서 **[확정]**

| 순서 | 영역 | 내용 |
|---|---|---|
| 0 | 헤더 | 로고, 안내 버튼("처음이세요?"), 계정 |
| 1 | 시황 | 오늘 시장 한 줄 요약 + 기존 코스피/코스닥 카드 + 원/달러 (기존 요소 유지) |
| 2 | 시장이 주목하는 종목 | 내 설정에 맞는 종목 최대 3개. 종목명, 한 줄 이유, 살 만한 가격, 정리할 가격. 현재 성향 표시와 변경 진입점 |
| 3 | 지난달 성과 | 기존 추천 성과 유지 (5장 참고) |
| 4 | 하단 탭 | 오늘 / 성과 / 내 것 / 더 보기 |

- '추천'이라는 단어 대신 **"시장이 주목하는 종목"**을 쓴다. **[확정]**
- 가입하지 않아도 홈 전체를 볼 수 있다. **[확정]**
- 디자인은 현재 양봉상회의 색·글꼴에 녹인다. **[확정]**
- 시황 한 줄 요약의 표현(맑음/흐림 vs 오르는 날/내리는 날)은 테스트로 정한다. **[미결]**
- 주목 종목 제목 아래에 "지난달 이 조건 N개 중 M개 상승" 한 줄을 둔다. **[권고]**

### 4.2 모드 **[권고]**
- 간편 모드가 기본. 전문가 모드는 토글로 전환.
- 기존 화면(매수타점, 테마, 섹터, 전략, 차트 등)은 전문가 모드로 보존하고 신규 기능을 추가하지 않는다(동결).
- 고급 tier 조건·필터는 "전문가용"이라는 고지와 함께 제공한다. **[확정]** 고지는 처음 켤 때 1회 + 필터 옆 상시 배지. **[권고]**

### 4.3 용어 풀이 **[권고]**
- 용어 사전을 JSON으로 두고 공통 툴팁 컴포넌트로 표시한다. 첫 등장 시 한 줄 풀이, 누르면 설명.

| 기존 용어 | 바꿀 표현 |
|---|---|
| 매수타점 | 살 만한 가격 |
| 손절가 | 정리할 가격 (여기까지 떨어지면 정리) |
| 거래량 급증 | 평소보다 2배 많이 거래됨 |
| 추천 종목 | 시장이 주목하는 종목 |

- 상승은 빨강, 하락은 파랑(국내 관습 유지).

## 5. 성적표(지난달 성과) **[확정]**

- 현행 유지. 변경하지 않는다.
  - 지난달 표시한 종목이 표시일 이후 최대 몇 %까지 올랐는지
  - 실패한 종목은 자세히 보여주지 않고 평균 손실이 몇 %였는지 정도만
- 숫자 옆에 **"표시일 이후 최고가 기준"** 한 줄을 붙인다. **[확정]**
- 실패 표시의 구체적 방식은 개발팀과 별도 논의. **[미결]**
- 투명성이 차별점이므로 숫자를 깎거나 가리는 변경은 하지 않는다. **[확정]**
- 이 숫자를 외부 광고 문구에 쓰지 않는다. **[권고]**

## 6. 설정 구조(성향 맞춤)

- 최초 preset은 제안으로 주고, 이후 사용자가 설정값을 직접 바꿔 자기 입맛에 맞는 종목을 고른다. **[확정]**
- 지켜야 할 규칙 **[권고 — 재무팀, 법적 위험을 줄이기 위함]**
  - 같은 설정값이면 누가 보든 같은 종목 목록이 나와야 한다.
  - 설정값은 종목 조건만 받는다(보유 기간, 감당할 하락폭, 변동 크기, 회사 규모 등). 투자금·보유 종목 같은 개인 사정 입력 기능은 만들지 않는다.
  - 문구는 "추천해 드립니다"가 아니라 "내 조건에 맞는 종목".
- 단계적 개방: 처음에는 preset 선택만 보이고, 익숙해진 뒤 세부 조건을 연다. **[권고]** 개방 기준(사용 일수 등)은 **[미결]**.
- 알고리즘 tier
  - 기본(rule 기반: 20일선 돌파, 거래량 2배 등): 사용자 조건 조정·백테스트 대상
  - 고급(shape_proba): 조건으로 쪼갤 수 없으므로 사후 필터만. 전문가용 고지와 함께 제공 **[확정]**

## 7. 백테스트 (유료)

### 7.1 기능 **[확정]**
- 사용자가 본인 조건으로 과거 N년치 결과를 확인한다.
- 고급 tier(shape_proba)는 대상에서 제외한다. rule 기반 조건만.
- 매수 시나리오의 형태는 **[미결]**.
- 데이터: 현재 일봉 5년치. 가능하면 더 모은다.

### 7.2 표시 규칙
- **"과거 수익이 미래 수익과 같을 것이라고 생각하면 안 된다"**는 문구를 강조해 노출한다. **[확정]**
  - 하단 고지가 아니라 결과 숫자 바로 위에 고정, 첫 실행 때 확인 버튼 1회. **[권고]**
- 평균 수익만 보여주지 않는다. 손실 횟수와 가장 크게 잃은 구간을 함께 보여준다. **[권고]**
- 수수료·세금을 기본 반영한다. **[권고]**
- 계산 기준은 "살 만한 가격에 사서 정리할 가격 규칙대로 팔았을 때"로 한다. **[권고]**
- 무료 1년 결과에는 "1년은 판단하기에 짧은 기간"이라는 안내를 붙인다. **[권고]**

### 7.3 과금 — 2 track **[확정]**
| 구분 | 무료 | 유료 |
|---|---|---|
| 기간 | 최근 1년치 | 그보다 과거는 구독 |
| 실행 횟수 | 하루 5회 | 초과분은 코인 과금 (예: 5회 추가 4,900원). 구독자는 횟수 과금 없음 |

- 구독자 실행 횟수: CEO는 상품성 측면에서 무제한 선호. 개발팀 검토 결과 무제한 가능. **[권고]** 실행 간 10초 간격 제한만 두고, 약관에 "비정상적 자동 실행은 제한될 수 있다"를 넣는다.

### 7.4 서버 설계 **[권고 — 개발팀]**
- 서버: Mac mini M2 16GB. 일봉 5년치는 약 340만 행(2,700여 종목 × 250일 × 5년) 규모로 추정.
- 지표 사전 계산: 이동평균, 거래량 배수 등 조건 재료를 매일 밤 batch로 계산해 둔다.
- 결과 캐시: 같은 조건·기간 조합은 저장된 결과를 돌려주고 횟수를 차감하지 않는다.
- 대기열: 동시 계산 수를 2~3개로 고정하고 나머지는 줄을 세운다.
- 백테스트 계산은 매매·시세 수집과 다른 프로세스에서 돌린다.
- 출시 전 가상 사용자 20~30명 동시 실행으로 실측한다. 응답이 10초를 넘으면 일일 상한을 다시 논의한다.
- 확인 필요: 상장폐지 종목이 데이터에 포함돼 있는지. 빠져 있으면 결과가 실제보다 좋게 나온다. **[미결]**

## 9. 가입

- 가입 없이 홈 전체 공개. **[확정]**
- 가입이 필요한 시점: 성향 설정 저장, 알림, (유료) 백테스트. **[권고]**
- 가격 알림은 지연 시세 기준이다. "실시간 알림"이라고 표현하지 않는다. **[권고]**

## 10. 고지 문구 (화면에 들어가야 하는 것)

- 투자 판단과 그 결과의 책임은 이용자 본인에게 있습니다.
- 주식 투자는 원금 손실이 날 수 있습니다.
- 과거 성과는 앞으로의 수익을 보장하지 않습니다. (백테스트 화면에서는 강조)
- 성과의 상승률은 표시일 이후 최고가 기준입니다.
- 화면의 시세는 실제보다 몇 분 늦을 수 있습니다.
- 성향 테스트 결과는 시작 설정 제안이며 언제든 바꿀 수 있습니다.

## 16. 양봉상회 / 비밀상회 분리 (2026-11-15) **[확정]**

- 기존 앱은 private 고객 전용 **비밀상회**(트레이딩 유지), 새로 만드는 것이 **양봉상회**(트레이딩 완전 제거, 그 자리에 차트 보는 법 교육 '트레이닝' 탭).
- DB: 같은 MySQL 서버에 양봉상회 전용 스키마 `yangbong` + 별도 계정. 기존 `stock` 은 비밀상회와 시장 데이터 원본으로 그대로. SQL: `py-project/sql/yangbong/001~004`.
- 회원: **서비스별로 따로 관리한다.** **[확정]** 회원 테이블을 같이 쓰면 양봉상회 API 가 비밀상회 계정(매매 사용자 포함)의 비밀번호를 바꿀 수 있게 되어 분리 목적과 어긋난다(보안).
  - 기존 회원 9명은 전환 직전에 양봉상회로 한 번 복사해 가입 상태를 유지한다(`sql/yangbong/005`, KIS 키·매매 권한 제외). 이후 비밀번호 변경 등은 서비스마다 따로.
  - 기존 스토어 앱(com.aibeesworld.stocks)·도메인·Firebase·AdMob 은 양봉상회가 이어받고, 비밀상회는 새로 만든다.

| 구분 | 테이블 | 위치 |
|---|---|---|
| 공통(원본 `stock`, 양봉상회는 읽기 전용 뷰) | master_stock, stock_ohlcv_daily, stock_investor_daily, trade_buy_target_stock/basic/chart/perf_monthly, master_themes_group/code | 배치가 `stock` 에 쓰고 양봉상회는 읽기만 |
