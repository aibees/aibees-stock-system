# 아이디어 — 홈 상단 "주요 금융 이슈" 뉴스 영역

- 일시: 2026-11-15
- 제안: 사용자
- 상태: [미결] 아이디어 단계, 개발 착수 전

## 1. 제안
- 양봉상회 홈(HomeSimple) 상단, 원/달러 표시 바로 아래에 주요 금융 이슈를 짤막하게 볼 수 있는 공간을 둔다.
- 뉴스 크롤링으로 가능한지 방법을 검토한다.

## 2. 현황
- 코드에 뉴스 수집 기능은 없다(py-naver-stock-theme 의 AI 콘텐츠 생성 서비스가 뉴스 문구를 언급하는 정도).
- 홈은 지수 카드 → 원/달러 → … 순이며, 시장 스냅샷 API 가 지수·환율을 내려준다.
- 배치는 py-stock-batch(scheduler_app)에 주기 잡을 추가하는 구조.

## 3. 권고안: RSS 수집 → 배치 저장 → 앱은 DB 만 읽기

### 3-1. 수집원
- RSS 우선: 연합뉴스, 한국경제, 매일경제, 머니투데이 등 경제·증시 섹션. 실제 URL 은 구현 때 확인.
- 네이버 검색 API(뉴스): 무료 쿼터, "코스피/환율/금리" 키워드 보조용.
- 해외 이슈(미국 증시, 연준)가 필요하면 Google News RSS 검색 피드 추가.
- 네이버 금융 HTML 파싱은 차단·구조 변경 위험으로 비추천.

### 3-2. 저장·조회
- 평일 장중 10~15분 간격 수집 잡 추가.
- `market_news` 테이블: 제목, 출처, 링크, 발행시각, 링크 해시(중복 제거).
- 앱은 외부 사이트를 직접 호출하지 않고 조회 API 로 DB 만 읽는다.

### 3-3. 홈 표시
- 최근 5건 안팎을 한 줄씩. 제목 + 출처 + "n분 전"(옅은 글자, 뱃지 없음). 누르면 원문 링크 이동.
- 본문 저장·요약 노출은 저작권 위험이 있어 제목과 링크만 사용.

### 3-4. 선택: AI 한 줄 요약
- 수집한 제목 20~30개를 Claude 에 넘겨 "오늘의 금융 이슈 3줄" 생성, 하루 몇 번만 갱신.
- 제목만 입력으로 쓰고 결과는 자체 문장. 다만 사실 오류 가능성이 있어 "AI 요약" 표기 필요.

## 4. 선택지 비교
| 방식 | 장점 | 단점 |
|---|---|---|
| A. RSS 제목 + 링크 | 단순·안정, 법적 부담 낮음 | 언론사별 품질 차이, 자극적 제목 |
| B. A + AI 3줄 요약 | 읽기 편함, 날씨 비유와 어울림 | 호출 비용, 요약 오류 가능성 |
| C. HTML 크롤링 | 소스 자유 | 차단·구조 변경, 약관 문제 |
