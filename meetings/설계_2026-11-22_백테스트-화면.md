# 백테스트 화면 상세 명세

> 양봉상회 · 2026-11-22 확정 기준
> **이 화면은 유료결제를 유도하는 메인 페이지다.** 모든 설계 판단은 "결제 전환"과 "과대광고 금지" 두 축을 동시에 만족해야 한다.

---

## 1. 목적

| 구분 | 내용 |
|---|---|
| 사용자 가치 | 내가 만든 기준이 과거에 어떻게 작동했는지 직접 확인 |
| 사업 가치 | 구독 결제의 1순위 진입점. 체류시간 확보 |
| 교육 가치 | preset 값을 바꿔가며 결과 차이를 체감 → 기준을 스스로 만지게 만듦 |

**성공 지표**
- 백테스트 1회 이상 실행 사용자의 D7 재방문율
- 백테스트 실행 → 구독 결제 전환율
- 1회 세션당 평균 실행 횟수 (preset을 몇 번 만졌는가)

---

## 2. 진입 경로

1. 홈 → `내 기준` 카드 (기준 있음 상태) → **이 기준, 과거에 넣어보기**
2. 기준(preset) 편집 화면 하단 → **이 기준 테스트해보기**
3. 메뉴 → 백테스트

> 기준이 없는 사용자는 진입 불가. 먼저 preset 생성으로 보낸다. (기준 없이 돌리는 백테스트는 "앱이 골라준 결과"가 되어 앱 목표와 충돌)

---

## 3. 화면 흐름

```
[1] 설정        [2] 실행 중       [3] 결과
 기준 확인   →   진행 표시    →   요약 + 상세 + 과금 게이트
 기간 선택                        ↘ 기준 바꿔서 다시 돌리기 (→1)
```

### 3-1. 설정 화면

**블록 A — 기준 요약 (읽기 전용 + 편집 진입)**
- 현재 적용될 조건을 한 줄씩 자연어로 표시
  - 예: `20일 이동평균선 돌파` / `거래량 전일 대비 2배 이상` / `시가총액 1,000억 이상`
- 우상단 `기준 바꾸기 ›` → preset 편집 화면
- **고급(shape_proba) tier 조건은 백테스트 대상에서 제외.** 해당 조건이 preset에 포함돼 있으면 안내 문구 표시:
  > 고급 조건은 과거 테스트를 제공하지 않아요. 기본 조건만으로 계산돼요.

**블록 B — 기간 선택**
| 옵션 | 접근 |
|---|---|
| 최근 6개월 | 무료 |
| 최근 1년 | 무료 |
| 최근 3년 | 🔒 구독 |
| 최근 5년 | 🔒 구독 |

- 잠긴 옵션도 **비활성 처리하지 말고 탭 가능하게** 한다. 탭하면 결제 바텀시트.
- 잠금 아이콘 옆에 보유 데이터 범위 표기: `2021.01 ~ 2026.11`

**블록 C — 매수/청산 시나리오** *(※ 미결 사항 — 5장 참조)*
- 1차 구현 기본값: 신호 발생일 **종가 매수**, **20거래일 후 종가 청산**
- 사용자 조정 가능 항목(2차): 보유 기간(5/10/20/60일), 목표 수익률 도달 시 청산, 손절선

**블록 D — 실행 버튼 + 잔여 횟수**
- 버튼: `과거에 넣어보기`
- 버튼 하단 소형 텍스트: `오늘 남은 실행 3/5회` (구독자는 `무제한`)

---

### 3-2. 실행 중

- 소요 예상 2~5초. 스켈레톤 + 진행 문구
- 문구는 과정을 설명해 교육 효과를 겸한다
  - `2021년부터 조건에 맞는 날을 찾는 중`
  - `찾은 날마다 20일 뒤 주가를 확인하는 중`
- 10초 초과 시 타임아웃 → 재시도 안내

---

### 3-3. 결과 화면 ★ 가장 중요

> 설계 원칙: **무료 구간 결과는 전부 보여준다.** 가리는 것은 "더 긴 기간"뿐이다. 반쪽짜리 결과를 보여주고 결제를 요구하면 신뢰를 잃는다.

**① 헤드라인 카드**
```
최근 1년, 내 기준으로
조건에 맞은 날  42번
20일 뒤 평균    +3.8%
오른 경우       26번 (62%)
내린 경우       16번 (38%)
```
- 평균 수익률은 **승률과 반드시 함께** 표시. 평균만 단독 노출 금지.
- 숫자 아래 고정 고지:
  > 과거에 이랬다는 기록일 뿐, 앞으로도 같다는 뜻이 아니에요.

**② 기간별 분포 차트**
- X축 월, Y축 해당 월 신호의 평균 수익률. 양/음 막대
- **무료 구간(최근 1년)은 선명, 그 이전 구간은 흐리게 표시하고 자물쇠 오버레이**
- 오버레이 문구: `2021년부터 보려면` + `구독하고 5년치 보기` 버튼
- → 이 지점이 결제 전환의 1순위 포인트. 가치를 **보여준 뒤** 잠근다.

**③ 양봉상회 비교 (월별)**
- 같은 기간, 같은 월에 양봉상회 기본 기준이 골랐을 종목과 그 결과를 나란히 표시
- 표기 예: `11월 — 내 기준 +2.1% / 양봉상회 기준 +4.0%`
- **금지**: 양봉상회 성과만 단독 강조, 누적 수익률 자랑, "따라하세요" 류 문구
- 내 기준이 더 나은 달은 그대로 노출한다. 이게 자립심 목표와 맞물리는 지점

**④ 개별 신호 리스트**
- 날짜 / 종목 / 진입가 / 청산가 / 수익률
- 손실 건도 **숨기지 않고 동일한 비중으로** 표시
- 각 행 탭 → 해당 시점 차트 + 신호 설명 (홈의 "이번 주의 차트"와 동일 컴포넌트 재사용)

**⑤ 하단 CTA 2개**
- `기준 바꿔서 다시 돌리기` (주 버튼) → 설정 화면, 남은 횟수 차감 예고
- `구독하고 5년치 보기` (보조 버튼)

## 4. 과금 설계

### 4-1. 2 track

| Track | 무료 | 유료 |
|---|---|---|
| **기간** | 최근 1년까지 | 1년 초과 구간은 구독 |
| **실행 횟수** | 하루 5회 | 초과 시 코인 과금 (예: 5회 추가 4,900원). 구독자는 횟수 제한 없음 |

- 구독 가격대: 6,000~9,900원/월 (확정 전)
- 구독자 실행 무제한이 원칙. 서버 부하 대응은 개발에서 처리(캐시/큐잉, 7장 참조)

### 4-2. 과금 게이트가 뜨는 지점 (3곳)

| # | 트리거 | UI | 문구 방향 |
|---|---|---|---|
| G1 | 잠긴 기간 옵션 탭 | 바텀시트 | "2021년부터 돌려보려면 구독이 필요해요" |
| G2 | 결과 차트의 흐린 구간 탭 | 바텀시트 | 동일 |
| G3 | 일일 5회 소진 후 실행 | 모달 (2선택) | "오늘 실행을 다 썼어요" → `구독하기` / `5회 더 받기 4,900원` |

### 4-3. 전환 설계 원칙

1. **먼저 쓰게 하고 나중에 막는다.** 첫 실행은 어떤 경우에도 무료로 끝까지 보여준다.
2. **잠긴 것의 가치를 먼저 보여준다.** 흐린 차트는 "뭐가 있는지"는 보이게 — 완전한 블랭크 금지.
3. **횟수 게이트는 preset을 만진 사람에게만 닿는다.** 하루 5회는 진지하게 조정하는 사용자만 도달하는 선 → 과금 대상이 곧 고관여 사용자.
4. 결제 유도 문구에 **기대 수익을 암시하지 않는다.** "더 벌 수 있어요" 금지. "더 긴 기간을 확인할 수 있어요"만.

## 7. 계산 정의

| 항목 | 정의 |
|---|---|
| 신호 발생일 | preset 조건을 모두 만족한 거래일 |
| 진입가 | 신호 발생일 **종가** |
| 청산가 | 진입일 + N거래일 종가 (기본 N=20) |
| 수익률 | `(청산가 - 진입가) / 진입가 × 100`, 수수료·세금 미반영 (화면에 명시) |
| 평균 수익률 | 전체 신호 수익률의 **산술평균** (누적 복리 아님 — 명시 필요) |
| 승률 | 수익률 > 0 인 신호 수 / 전체 신호 수 |
| 미청산 처리 | 청산일이 데이터 범위를 넘으면 해당 신호 제외, 제외 건수를 화면에 표기 |

> ⚠️ 홈의 성적표가 쓰던 "추천일 이후 최대 상승률"과 **계산 방식이 다르다**. 백테스트는 고정 보유기간 기준. 같은 종목인데 숫자가 다르게 보일 수 있으므로 화면에 계산 기준을 반드시 명시한다.

## 8. 고지 문구 (필수)

결과 화면 상단 고정 1개 + 하단 상세 1개.

**상단 (요약 카드 안)**
> 과거에 이랬다는 기록일 뿐, 앞으로도 같다는 뜻이 아니에요.

**하단 (접기 가능)**
> - 수수료, 세금, 슬리피지는 계산에 넣지 않았어요.
> - 거래량이 적은 종목은 실제로 그 가격에 사거나 팔지 못할 수 있어요.
> - 상장폐지·거래정지 종목은 계산에서 빠졌어요.
> - 투자 판단과 그 결과는 본인에게 있어요.

## 9. QA 체크리스트

- [ ] 조건에 맞는 날이 0건일 때 빈 화면 처리 (조건을 완화해보라는 안내)
- [ ] 신호가 500건 이상일 때 리스트 페이징
- [ ] 비구독자가 URL/파라미터 조작으로 `periodMonths=60` 요청 → 서버 차단 확인
- [ ] `lockedPeriod` 응답에 실제 수익률 값이 섞여 나가지 않는지 확인
- [ ] 횟수 차감이 실패한 실행에서는 일어나지 않는지 (타임아웃·에러 시 롤백)
- [ ] 고급 tier 조건 포함 preset의 제외 안내가 뜨는지
- [ ] 수익률 색상(빨강/파랑)이 명도로도 구분되는지 (색각 접근성)
- [ ] 결제 직후 잠긴 구간이 새로고침 없이 열리는지

## 10. 서버 부하 대응 (개발 검토)

- `(presetId 해시 + 기간 + 청산조건)` 키로 결과 캐시. 당일 재실행은 캐시 응답
- 일 단위 배치로 종목별 신호 발생일 사전 계산 → 실행 시에는 조인만
- 구독자 무제한 정책 유지하되, 동시 실행은 사용자당 1건으로 제한하고 큐잉
