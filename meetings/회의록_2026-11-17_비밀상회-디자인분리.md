# 회의록 — 비밀상회 디자인 분리

- 일자: 2026-11-17
- 참석: CEO, 기획팀, 디자인팀, 개발팀
- 안건: 비밀상회 / 양봉상회를 구분할 수 있는 디자인(색·로고·타이틀) 결정

## 0. 배경 / 사전 확인 현황

- 도메인 변경 작업 완료 (별건)
- `yangbong-store-vue` / `secret-store-vue` 두 레포 존재하나 아래가 완전 동일한 상태
  - `capacitor.config*.json` → appId `com.aibeesworld.stocks`, appName `양봉상회`
  - `brand/logo.svg`, `brand/app-icon-1024.png` (벌집 육각형 + 꿀단지 + 양봉 3개)
  - `index.html` theme-color `#FFC107`, title `양봉상회`
  - splash backgroundColor `#FFFDD0`
- 디자인 토큰: 무채색 `$dc-*` (원래 `/trade` 대시보드용 "네모 반듯·무채색" 시스템) + 양봉 브랜드 `$yb-yellow/$yb-honey/$yb-cream/$yb-brown`

## 1. 결정사항

### 1-1. 앱 정체성

| 항목 | 결정 |
|---|---|
| 앱 이름 | `비밀상회` 고정 |
| 스토어 등재 | **없음** (사이드로드 / 내부 배포만) |
| 대상 | 본인 · 가족 · 소수 지인 |
| 성격 | 실제 자동 트레이딩 현황 조회 전용 |
| 큰 구조 | 현행 유지 (대규모 리뉴얼 없음) |
| 레포 전략 | **Vue 프로젝트만 완전 분리, backend는 공용** |
| 로고 | **벌집 육각형 유지** (Chagok Labs 집안 표식) |

### 1-2. 로고 / 아이콘

- 양봉상회: 육각형 **노랑 면 채움** + 꿀단지 + 양봉 3개 (현행 유지)
- 비밀상회: 육각형 **면 없음, 실버 외곽선** + 내려진 셔터 한 줄
- 구분 원리: 면이 "채워졌는지 / 비었는지" 로 갈리므로 작은 앱 아이콘 크기에서도 식별 가능
- "비밀" 콘셉트(자물쇠·금고·가면)는 채택하지 않음 — 같은 집안의 다른 등급이라는 느낌을 유지

### 1-3. 테마 — 사용자 선택형 3종

CEO 결정: 가족 제공 서비스로서의 편의이므로 테마 선택 기능을 넣는다.

| 테마 | 성격 | 기본값 |
|---|---|---|
| `dark-teal` | 다크 + 틸 포인트 | **기본 (확정)** |
| `light-violet` | 라이트 무채색 + 바이올렛 | |
| `light-rose` | 라이트 로즈 + 딥로즈 포인트 | |

- 기본 테마는 `dark-teal` **확정** (CEO 결정). 아이콘 · 스플래시 · theme-color 모두 이 기준으로 제작.
- 핑크는 **라이트 로즈** 채택 (CEO 결정). 다크 로즈안은 폐기.
- 라이트 로즈 보완책: 페이지 배경만 `#FDF2F7`, **카드 면은 순백 `#FFFFFF`**, 수익률 상승색은 한 단 진한 `#A32D2D` 사용 → 붉은 배경에 붉은 숫자가 묻히는 문제 방지
- 네이비+실버안: **폐기** (하락 파랑이 네이비 배경에 묻혀 의미색이 안 읽힘)

### 1-4. 색 운용 원칙 (3테마 공통 · 절대 규칙)

> **의미색(상승 빨강 / 하락 파랑)은 테마와 무관하게 불변.**
> 테마가 바꾸는 것은 배경 · 면 · 테두리 · 텍스트 · 포인트 **5종뿐.**
> **포인트색은 수익률 숫자에 절대 쓰지 않는다.** 상태 배지(AUTO ON) · 활성 탭 · 버튼에만 사용.

이 규칙이 없으면 핑크 포인트가 상승 빨강과, 틸/바이올렛 포인트가 등락 직관과 간섭한다.

### 1-5. 브랜드 식별과 테마의 역할 분리 (중요)

스플래시 `backgroundColor`와 앱 아이콘은 **빌드 타임 고정**이라 런타임 테마를 따라갈 수 없다. 따라서:

- **구분 책임은 아이콘 · 스플래시 · 로고가 진다** → 테마와 무관하게 1종 고정
- **테마는 앱 내부 화면의 취향 설정일 뿐** → 구분 책임 없음
- 따라서 "핑크 테마용 아이콘"은 만들지 않는다
- 상태바(StatusBar 플러그인)만 런타임으로 테마에 맞춰 조정

### 1-6. 테마 선택 UI 배치

- **설정 화면 안쪽 1depth**에 배치
- 홈/상단바에 토글 노출 금지 (하루 한 번도 안 바꿀 기능에 상단 공간을 내주지 않음)

## 3. 개발 작업 (실행 순서)

선행 전제: **SCSS 변수는 컴파일 타임이라 런타임 전환이 불가능.** CSS custom property 구조로 전환해야 한다.

1. **하드코딩 색 전수 청소** — `secret-store-vue` 전체에서 `#FFC107` / `#FFFDD0` / `#F9E076` / `#895129` / `#4A2A12` grep → 전부 변수 참조로 치환
   - 이 단계가 전체 비용의 약 90%. 테마를 1개로 가도 어차피 필요한 작업
2. **`:root` CSS 변수 선언 + `[data-theme="..."]` 오버라이드 구조 구축** (`sass/__variables.scss` 개편, `$sc-*`는 `var(--sc-*)` 참조 껍데기로)
3. **테마 전환 로직** — `<html data-theme>` 속성 토글 (리렌더 불필요)
4. **테마 저장** — Capacitor **Preferences** 플러그인 사용 (localStorage는 iOS 웹뷰에서 날아가는 케이스 있음)
5. **appId 분리** — `com.aibeesworld.secretstore`, appName `비밀상회`
   - 스토어 등재는 없지만, **한 기기에 양봉상회와 동시 설치하려면 필수** (같으면 덮어씀)
   - `capacitor.config.json` / `.dev.json` / `.prod.json` 3개 모두
   - Android `strings.xml`, iOS `Info.plist`
6. **Firebase 앱 등록 추가** — FCM 사용 중이므로 신규 appId로 앱 등록 필요 (backend는 공용 유지)
7. **brand 교체** — `brand/logo.svg`, `brand/app-icon-1024.png` 신규 제작
8. **`index.html`** — title `비밀상회`, theme-color 기본 테마값
9. **splash backgroundColor** — 기본 테마 기준으로 고정
10. **StatusBar 플러그인** — 테마 전환 시 상태바 스타일 동기화
11. **차트 색 재점검** — `sass/charts` 전수 점검. Chart.js 옵션은 JS 객체라 CSS 변수가 자동 반영되지 않으므로, 테마 전환 시 차트 인스턴스 재생성 또는 옵션 갱신 핸들러 추가 필요
12. **QA** — 테마 3종 × 전 화면. 특히 라이트 테마에서만 안 보이는 텍스트 케이스 집중
