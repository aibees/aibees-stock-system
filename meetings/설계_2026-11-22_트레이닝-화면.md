# 트레이닝(차트 퀴즈) 상세 명세

> 양봉상회 · 2026-11-22 확정
> 디자인: **A안 벌집 라이트** 확정. B안(다크)은 추후 다크모드 테마로 흡수.
> 시안 캔버스: `Training-Q.dc.html`(문제), `Training-Result.dc.html`(결과)

---

## 1. 범위와 원칙

트레이닝은 **아카이브(패턴 DB)를 소재로 자동 생성되는 차트 판독 퀴즈**다.

**설계 원칙 4가지**

1. **행동 권유 표현을 쓰지 않는다.** 선택지는 매수/매도가 아니라 **상승 / 보합 / 하락**. 질문은 "20일 뒤, 어느 쪽일까요?"
2. **"정답"이라 부르지 않는다.** 결과는 판정이 아니라 **대조**다. UI·내부 필드명·로그 전부 `match` 계열로 통일.
3. **한 건의 결과로 판단을 평가하지 않는다.** 결과 화면 하단에 같은 패턴의 과거 분포(상승/하락 횟수)를 반드시 함께 노출.
4. **종목을 특정하지 않는다.** 종목명·날짜 비공개, 기준일 종가를 100으로 정규화.

**연결 루프**
```
트레이닝 → (결과 화면) → 패턴 아카이브 → 내 기준(preset) → 백테스트
```
결과 화면의 `이 조건 내 기준에 넣기` 버튼이 이 루프의 연결 고리다.

## 3. 화면 명세

### 3-1. 문제 화면

| 영역 | 내용 |
|---|---|
| 헤더 | 닫기 버튼 · `TRAINING` (letter-spacing 1.4px) · 육각형 진행 표시 3개 |
| 기준가 | `106.2` + 라벨 "기준가 100 기준" + 우측 `Lv.2 · 이동평균 + 거래량` 뱃지 |
| 차트 카드 | 범례(5일/20일/60일) → 캔들+MA 차트(358×220) → 거래량 막대(358×44) |
| 지표 토글 | 이동평균 / 거래량 / RSI / MACD / 볼린저 — 활성은 `--honey-soft` 배경 |
| 질문 | "20일 뒤, 어느 쪽일까요?" + `힌트 보기 · 점수 20% 차감` |
| 선택지 | 상승 ▲ / 보합 ─ / 하락 ▼ — 외곽선 버튼, 아이콘 + 라벨 |

**지표 토글 동작**
- Lv에 따라 **기본 켜짐 상태**가 다르지만, 사용자는 모든 지표를 켜고 끌 수 있다
- 끄고 켜는 행위 자체가 preset 조작 연습이므로 제한하지 않는다
- 토글 상태는 다음 문제에 유지 (세션 내)

**힌트**
- 누르기 전에는 신호 설명을 일절 노출하지 않는다 (현 운영 화면은 질문문에 답이 들어 있어 수정 필요)
- 누르면 1~2줄 설명 노출, 해당 문제 점수 ×0.8
- 힌트 미사용으로 일치하면 결과 화면에 `힌트 없이 맞춤` 표기

### 3-2. 결과 화면

| 순서 | 영역 | 내용 |
|---|---|---|
| 1 | 판정 배지 | 짙은 갈색 카드 + 육각형 마크. **"같은 방향을 봤어요"** / 불일치 시 "다른 방향이었어요". 하단 소형: `내 선택 상승 · 20일 뒤 실제 +7.4%` |
| 2 | 차트 | 선택 시점 이후 20봉이 이어져 그려짐. 이후 구간 배경 `#F3EDDD`, 경계 점선 `#CBB173` |
| 3 | 숫자 3종 | 20일 뒤 / **가는 길 최저** / 최고 |
| 4 | 해설 | 육각형 마커 + "무슨 일이 있었나" + 2~4문장 |
| 5 | 패턴 통계 | 발생 N번 / 상승 N번 / 하락 N번 + 비율 막대 + `이 패턴 사례 N건 전체 보기 🔒` |
| 6 | CTA | `이 조건 내 기준에 넣기`(honey) / `다음 문제`(invert) |
| 7 | 고지 | 수수료·세금 미반영, 특정 종목 매매 권유 아님 |

**"가는 길 최저"가 핵심 교육 장치다.** 최종 수익률만 보여주면 "맞췄다"로 끝나지만, 중간에 -4%까지 밀린 사실을 함께 보여줘야 보유의 어려움이 전달된다. 시안의 예시 케이스(+7.4% 종료 / 중간 -4.0%)가 이 의도다.

**차트 연장 연출**
선택 직후 이후 20봉이 **왼쪽에서 오른쪽으로 순차 렌더**되도록 한다 (약 600~800ms). 이 순간의 체감이 재방문 동기다. 접근성을 위해 `prefers-reduced-motion` 시 즉시 표시.

## 4. 문제 자동 생성 파이프라인

일 1회 배치(장 마감 후). 아카이브 스캔과 동일 파이프라인을 공유한다.

```
① 기준일 선정      오늘 - 20거래일 이전 (D+20 결과가 존재해야 하므로)
② 패턴 스캔        등록된 패턴 조건으로 전 종목 스캔
③ 후보 필터        아래 제외 규칙 적용
④ 결과 라벨링      D+20 종가로 outcome 계산
⑤ 정규화           기준일 종가 = 100 으로 전 구간 스케일
⑥ 난이도 산정      Lv1~4
⑦ 스냅샷 저장      차트 렌더에 필요한 데이터 전부를 JSON으로 동결
```

**③ 제외 규칙**
- 관리종목, 투자경고/위험, 거래정지 이력 있는 종목
- 스팩, 우선주, ETF/ETN
- 기준일 거래대금 10억 미만
- 액면분할·병합 등 수정주가 이슈 구간
- 최근 90일 내 같은 종목이 이미 출제된 경우
- 기간 중 상장폐지

**⑥ 난이도 산정**

| Lv | 조건 | 기본 켜짐 지표 |
|---|---|---|
| 1 | 단일 신호 + 거래량 3배 이상 + \|결과\| ≥ 10% | 이동평균 |
| 2 | 거래량 2배 이상 + \|결과\| 5~10% | 이동평균, 거래량 |
| 3 | 보조지표 해석이 필요한 케이스 + \|결과\| 5% 내외 | + RSI, MACD |
| 4 | 복합 신호 / 속임수 돌파 포함 | 전체 |

**⑦ 스냅샷을 동결하는 이유**
수정주가가 나중에 바뀌면 과거 문제의 차트와 결과가 달라진다. 출제 시점에 계산한 값을 그대로 저장해 두고, 이후 원본 데이터 변경과 무관하게 재현한다.

**스냅샷 JSON 구조**
```json
{
  "normalizedBase": 13230,
  "candles": [{ "t": "D-119", "o": 107.4, "h": 108.3, "l": 106.0, "c": 106.8, "v": 52 }],
  "indicators": {
    "ma": { "5": [...], "20": [...], "60": [...], "120": [...] },
    "rsi14": [...], "macd": { "macd": [...], "signal": [...], "hist": [...] },
    "bollinger": { "upper": [...], "mid": [...], "lower": [...] }
  },
  "futureCandles": [ ... 20개 ... ]
}
```
- 과거 구간 120봉, 미래 구간 20봉
- 지표는 **서버에서 전부 계산**해 배열로 저장. 클라이언트는 렌더만 한다

## 5. 채점 규칙

```
ret        = (close[D+20] - close[D]) / close[D] * 100
direction  = ret >=  5.0  → UP
             ret <= -5.0  → DOWN
             그 외         → FLAT

isMatch    = (answer == direction)
score      = 100
             × (usedHint ? 0.8 : 1.0)
             + streakBonus
```

- 임계값 ±5%, 보유기간 20거래일은 **백테스트 기본값과 동일**하게 유지한다. 두 화면에서 숫자가 다르면 사용자가 혼란스러워진다.
- `streakBonus`: 연속 일치 3회부터 +10, 5회부터 +20 (상한 +20)
- 연속 학습일(streak)은 **일 단위 출석** 기준이며 점수와 별개

**표현 매핑 — 반드시 지킬 것**

| 내부 값 | UI 표기 |
|---|---|
| `isMatch = true` | 같은 방향을 봤어요 |
| `isMatch = false` | 다른 방향이었어요 |
| `direction` | (라벨 노출 금지, 실제 수익률로만 표기) |

## 6. 데이터 모델

```sql
-- 패턴 정의
CREATE TABLE pattern (
  id            BIGINT PRIMARY KEY AUTO_INCREMENT,
  code          VARCHAR(64) NOT NULL UNIQUE,   -- MA20_BREAK_VOL2
  name          VARCHAR(128) NOT NULL,         -- 20일선 돌파 + 거래량 2배
  description   TEXT,
  condition_json JSON NOT NULL,
  tier          VARCHAR(16) NOT NULL,          -- BASIC / ADVANCED
  is_public     BOOLEAN NOT NULL DEFAULT TRUE, -- ADVANCED 는 FALSE
  created_at    DATETIME NOT NULL
);

-- 패턴별 집계 (아카이브 통계 · 결과 화면에서 사용)
CREATE TABLE pattern_stat (
  pattern_id    BIGINT NOT NULL,
  window_months INT NOT NULL,        -- 12, 36, 60
  occurrences   INT NOT NULL,
  up_count      INT NOT NULL,
  down_count    INT NOT NULL,
  flat_count    INT NOT NULL,
  computed_at   DATETIME NOT NULL,
  PRIMARY KEY (pattern_id, window_months)
);

-- 출제 문제
CREATE TABLE training_question (
  id            BIGINT PRIMARY KEY AUTO_INCREMENT,
  pattern_id    BIGINT NOT NULL,
  stock_code    VARCHAR(12) NOT NULL,   -- 내부 전용. 응답에 절대 포함 금지
  base_date     DATE NOT NULL,          -- 내부 전용
  level         TINYINT NOT NULL,       -- 1~4
  snapshot_json JSON NOT NULL,
  outcome_json  JSON NOT NULL,          -- { ret, direction, maxDrawdown, maxGain }
  explanation   TEXT NOT NULL,
  hint          VARCHAR(255) NOT NULL,
  created_at    DATETIME NOT NULL,
  UNIQUE KEY uk_q (stock_code, base_date, pattern_id)
);

-- 사용자 응답
CREATE TABLE training_attempt (
  id            BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id       BIGINT NOT NULL,
  question_id   BIGINT NOT NULL,
  answer        VARCHAR(8) NOT NULL,    -- UP / FLAT / DOWN
  used_hint     BOOLEAN NOT NULL,
  is_match      BOOLEAN NOT NULL,
  score         INT NOT NULL,
  answered_at   DATETIME NOT NULL,
  UNIQUE KEY uk_ua (user_id, question_id)
);

-- 일일 출제 세트
CREATE TABLE training_daily_set (
  user_id       BIGINT NOT NULL,
  set_date      DATE NOT NULL,
  question_ids  JSON NOT NULL,
  PRIMARY KEY (user_id, set_date)
);
```

> `stock_code`와 `base_date`는 **어떤 API 응답에도 포함하지 않는다.** 노출되면 사용자가 실제 차트를 찾아 답을 알 수 있고, 특정 종목 추천으로 읽힐 소지도 생긴다.

## 7. API 명세

### `GET /api/training/today`
```json
{
  "setDate": "2026-11-22",
  "quota": { "isSubscriber": false, "dailyLimit": 3, "used": 0, "remaining": 3 },
  "streakDays": 6,
  "questions": [
    {
      "questionId": 90412,
      "level": 2,
      "defaultIndicators": ["MA", "VOLUME"],
      "availableIndicators": ["MA", "VOLUME", "RSI", "MACD", "BOLLINGER"],
      "basePrice": 106.2,
      "baseChangeRate": 3.1,
      "snapshot": { "candles": [], "indicators": {} }
    }
  ]
}
```
- `snapshot`에는 **과거 120봉만** 포함. `futureCandles`는 응답하지 않는다

### `POST /api/training/{questionId}/hint`
```json
{ "hint": "거래량이 직전 평균보다 크게 늘어난 구간을 보세요.", "scoreMultiplier": 0.8 }
```

### `POST /api/training/{questionId}/answer`
요청 `{ "answer": "UP", "usedHint": false }`
```json
{
  "attemptId": 55120,
  "isMatch": true,
  "score": 100,
  "outcome": { "returnRate": 7.4, "maxDrawdown": -4.0, "maxGain": 8.1 },
  "futureCandles": [ ... 20개 ... ],
  "explanation": "마지막 두 봉에서 20일선을 위로 뚫었고 …",
  "pattern": {
    "patternId": 7,
    "name": "20일선 돌파 + 거래량 2배",
    "stat": { "windowMonths": 12, "occurrences": 38, "upCount": 21, "downCount": 17 },
    "caseListLocked": true
  },
  "nextQuestionId": 90413
}
```
- **답변 제출 전에는 `futureCandles`와 `outcome`을 절대 내려보내지 않는다.** 클라이언트에 미리 주면 추출 가능

### `GET /api/training/history`
오답 다시 풀기 목록. 비구독자는 `403 SUBSCRIPTION_REQUIRED`

## 8. 과금과 제한

| 항목 | 무료 | 구독 |
|---|---|---|
| 하루 문제 수 | 3문제 | 무제한 |
| 난이도 | Lv1~2 | Lv1~4 |
| 오답 다시 풀기 | ✗ | ✓ |
| 패턴 사례 전체 보기 | 요약 + 3건 | 전체 |

- 게이트는 **백테스트·아카이브와 같은 구독 1종**으로 묶는다 (6,900원 안)
- 3문제 소진 시 모달: `구독하기` / `내일 다시 오기`
- **첫날 3문제는 어떤 경우에도 끝까지 보여준다.** 중간에 막지 않는다

## 9. 문구 규칙

**금지**

| 쓰지 않음 | 대신 |
|---|---|
| 정답 / 오답 | 같은 방향 / 다른 방향 |
| 매수 / 매도 | 상승 / 하락 |
| 승률 68% | 38번 중 21번 상승 (+ 비율 막대) |
| 오를 가능성이 높아요 | 과거 이 조건에서는 … 였어요 |
| 추천 / 유망 / 기회 | (사용 금지) |

**필수 고지**
- 패턴 통계 아래: `최근 1년 기록이에요. 앞으로도 같다는 뜻은 아니에요.`
- 결과 화면 최하단: `실제 과거 데이터예요. 수수료와 세금은 넣지 않았고, 특정 종목의 매매를 권하는 내용이 아니에요.`

- [ ] `prefers-reduced-motion` 에서 차트 연장 애니메이션이 생략되는지
- [ ] 상승/하락이 색뿐 아니라 ▲▼ 아이콘으로도 구분되는지
- [ ] 패턴 통계의 발생 건수가 0인 문제가 출제되지 않는지
- [ ] 고급(ADVANCED) tier 패턴이 문제로 출제되지 않는지 (`is_public = FALSE`)

## 11. 구현 순서 제안

1. `pattern`, `training_question` 테이블 + 배치로 문제 100건 선적재
2. `GET /api/training/today` + 문제 화면 (지표 토글 없이 MA/거래량 고정)
3. `POST answer` + 결과 화면 (차트 연장 포함)
4. `pattern_stat` 집계 배치 + 결과 화면 통계 블록
5. 지표 토글 확장 (RSI / MACD / 볼린저)
6. 과금 게이트 + 오답 다시 풀기
7. 연속 학습일 / 점수

1~3까지가 최소 동작 단위다.
