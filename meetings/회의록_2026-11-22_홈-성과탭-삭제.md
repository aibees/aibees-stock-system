# 회의록 — 홈 성과 탭 삭제와 대체 블록

- 일시: 2026-11-22
- 안건 제출: CEO
- 참석: 기획, 마케팅, QA, 개발, 디자인

## 안건

홈 화면의 "양봉상회 성과" 탭을 삭제할지. 사용자가 스스로 공부하고 자기 기준으로 투자하게 한다는 앱 목표를 해치는 정보로 보임. 반면 추천 실력을 보여주는 자료라 홍보에는 유리.

## 논의

**기획** — 삭제 찬성. 11/16에 확정한 "교육 콘텐츠 앞단 + preset 직접 조작으로 자립심" 방향과 정면 충돌. 홈에 성과가 있으면 첫 메시지가 "공부할 필요 없다"가 됨. 다만 데이터 자체는 자산이므로 삭제가 아니라 위치 이동으로 봐야 함.

**마케팅** — 반대. 홈에서 빼면 신뢰 근거가 사라짐. 월별 성과는 리텐션 트리거이기도 함.

**기획 재반박** — "이번 달도 맞췄다"로 리텐션을 잡으면 결국 리딩방이 됨. preset·백테스트·교육이 전부 장식이 되고 과금 모델도 같이 죽음.

**CEO 결론** — 성과 전면 노출 폐지. 11/14의 "성적표는 부가기능이라 대표 메시지가 될 수 없다"는 결론의 연장선. 단, 백테스트 안에서 월별로 "양봉상회는 이렇게 추천했을 것"을 보여주는 것은 허용.

### 대체 블록

- 성향 테스트 카드 → **기각** (이미 "처음이세요?" 버튼에 있음)
- 마케팅 제안 "오늘의 차트 한 장" → 채택. 성과 섹션이 소비형이었으므로 대체재도 소비형이어야 함
- CEO 제안 — 전 주 선정 종목 하나의 차트를 보여주며 "양봉상회는 이 종목을 이럴 때 골랐어요" 교육 설명 → 채택, 위 블록의 구체안으로 확정
- 기획 조건 — 선정은 "많이 오른 종목"이 아니라 **"신호가 선명한 종목"** 기준. 주기적으로 오르지 않은 케이스도 편성
- 마케팅 조건 — 주체 표기는 "양봉상회"로 통일
- QA 조건 — 날짜·당시 가격·신호 조건은 실제 선정 이력과 일치시킬 것. 사후 각색 금지

## 결정 사항

1. 홈의 "양봉상회 성과" 섹션 삭제
2. "AI 분석 종목 TOP 3" → "시장이 주목하는 종목"으로 리네이밍
3. 신설 **이번 주의 차트** — 전 주 선정 종목 1개 + 차트에 선정 시점 마커 + 신호 설명 3줄 + 트레이닝 진입 + 수익 보장 아님 고지
4. 신설 **내 기준 카드** — 로그인/preset 상태별 3분기
   - A 로그인 전 → 로그인하고 내 기준 만들기
   - B 로그인·기준 없음 → 내 기준 만들기
   - C 기준 있음 → 걸린 종목 + 조건 요약 + 백테스트 진입
5. 홈 순서: 시황 → 시장이 주목하는 종목 → 이번 주의 차트 → 내 기준 → 공지사항
6. 성과 숫자는 홈에서 전부 제거. 백테스트 내부 비교 형태로만 잔존
