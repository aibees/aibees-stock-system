# 개별차트에 나오는 용어 목록

개별차트(쉬운 보기 · 자세히)와 분석 요약에 화면 글자로 나오는 용어를 모았습니다.
출처: `ChartStock.vue`, `LwStockChart.vue`, `chartAnalysis/layers.js`, `ChartAnalysisSummary.vue`,
서버 `stock_shared/chart_analysis/*.py` 의 라벨. 작성 기준일 2026-11-24.

상태: ✅ 단어장에 있음 · ➕ 아직 없음(추가 대상)
