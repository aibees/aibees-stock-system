# 양봉상회 과업 우선순위

기준일: 2026-11-18. 크기는 작음(한 번의 작업), 중간(시안 확인 포함), 큼(서버 작업 포함)으로 나눴다.

## 1순위: 출시 전 필수

| 순서 | 과업 | 해야 할 일 | 크기 | 담당·선행 조건 |
|---|---|---|---|---|
| 1 | 남은 표현 정리 | 앱 화면 문구는 교체 완료. 이용약관의 `매수 추천 종목`, `추천 성과`와 서버 메뉴명 `매수추천`을 정리 | 작음 | 약관은 2번 법적 검토와 함께 수정 |
| 2 | 법적 검토 | 유사투자자문업 해당 여부, 성과 표시와 광고 문구 확인 | 외부 | 전문가 확인 필요. 유료화 전 완료 |
| 3 | 용어 사전 사실 확인 | 상한가·하한가, 정규장, 시간외 거래, 공매도, 거래정지부터 검수 | 중간 | 공식 자료 대조 |
| 4 | 이모지 라이선스 표기 | Noto 이모지 라이선스 확인 후 앱 안 표기 정리 | 작음 | 출시 전 |
| 5 | 실제 기기 확인 | 첫 실행, 알림 권한 창, 보상형 광고 추적 권한, 실서버 일봉 조회 확인 | 작음 | iOS·Android 빌드 필요 |
| 6 | 상담 창구와 고객지원 | 카카오톡 채널(또는 오픈채팅) 상담 개설, 메뉴에 FAQ·문의하기 구성. 사업자 개설 후 개인정보 보호책임자에 전화번호 추가 | 중간 | 현재 문의는 chagoklabs@gmail.com |

## 완료

- 화이트 + 연한 꿀빛 디자인 개편, Pretendard 통일
- 트레이닝 첫 화면, 수업 6개 장 36단계, 퀴즈 모음, 용어 사전 70개
- 앱 화면의 `추천` 표현을 `주목 종목`, `주목한 이유`, `선정일` 등으로 교체
- 첫 1분 흐름: 소개 한 장 → 질문 3개 → 맞는 종목 3개 → 관심 종목 담기 → 알림 제안
- 기기 저장 관심 종목, 홈의 내 관심 종목, 종목별 오늘의 소식 판단
